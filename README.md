# ficus-node-feed

Подписанные (`ssh-keygen -Y`, namespace `ficus-node-cmd`) и зашифрованные (age) наборы настроек для устройства.
Без ключей устройства и ключа подписи содержимое бесполезно: устройство отвергает всё, что не подписано доверенным ключом,
и всё, что не новее уже применённого.

Не принимаются Issues и Pull Requests.
